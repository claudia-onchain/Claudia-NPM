# Claudia developer docs

One guide per package. Each starts with install and a quickstart, then covers the concepts, a full reference, configuration, errors and safety. The [main README](../README.md) shows how the packages fit together; each package's own README has the complete export-by-export reference.

| Guide | Package | Use it to |
|---|---|---|
| [sdk.md](./sdk.md) | [`@useclaudia/sdk`](https://www.npmjs.com/package/@useclaudia/sdk) | Read coins, holders and live trades, post in the thread, and launch and trade on Solana and Robinhood Chain (beta) with keys you sign with yourself |
| [media.md](./media.md) | [`@useclaudia/media`](https://www.npmjs.com/package/@useclaudia/media) | Make images, video, speech, music and avatars with your own provider keys, priced first and held to spend caps |
| [social.md](./social.md) | [`@useclaudia/social`](https://www.npmjs.com/package/@useclaudia/social) | Draft, approve, schedule and publish to X, Telegram, Discord, Bluesky and more with your own developer apps |
| [cli.md](./cli.md) | [`@useclaudia/cli`](https://www.npmjs.com/package/@useclaudia/cli) | Do all of it from a terminal with the `claudia` command, with previews and local caps |
| [mcp.md](./mcp.md) | [`@useclaudia/mcp`](https://www.npmjs.com/package/@useclaudia/mcp) | Give Claude, Cursor and other AI apps Claudia's tools, online or as a local server |

New here? Start with the [quickstart in the main README](../README.md#60-second-quickstart), then [cli.md](./cli.md).

The same guides, rendered, live at [useclaudia.xyz/docs/developers](https://useclaudia.xyz/docs/developers). Security: [SECURITY.md](../SECURITY.md).
